# dbapi

MemberDatabase の Supabase 操作を抽象化する REST API に関する要件をまとめるディレクトリです。

## ドキュメント

- `requirements.md`: 現時点で確定している dbapi 要件
- `spec.md`: 実装開始向け統合仕様
- `supabase.md`: Supabase 側で実施すべき作業一覧
- `implement.md`: 実装方針・RLS/エラー/監査ログの具体案
- `endpoints.md`: エンドポイント一覧仕様
- `openapi.yaml`: OpenAPI 3.0 スキーマ
- `schema`: 既存スキーマ（文脈参照用）
