# 機能要件

- Discord名の変更 → 登録情報も変更(手動)
- 定期的にDiscord名が登録情報と同じかを確認 → 違う場合は通知
- 5月を目処に全部員に登録情報のアップデートを要請 → 更新が6月までにされていない部員は非アクティブ扱いにする
- Discordのロールを自動で変更したい
- 新入部員はDiscordサーバに参加 → 仮登録を作成(3日?で無効化) → Discordからポータルにアクセス → 本登録をして入部
- Webから色々操作したい
- 最終的には部内連絡とリマインドも実装したい
- FastAPIで全部API定義しとけば後々なんかあっても対応できそう
