# DiscordController

# システム要件

- ロールの作成 / 変更 / 削除ができる
- ロールの権限が変更できる
- ロール一覧が取得できる
- リアクションの集計ができる
- メッセージの送信 / 削除 / 編集
- チャンネルの権限が変更できる
- チャンネルの作成 / 変更 / 削除ができる
- チャンネル一覧が取得できる
- チャンネルにアクセスできるロールの一覧が取得できる
- メンバーの管理(キック / Ban等)ができる
- メンバー一覧が取得できる
- メンバーの持つロール一覧が取得できる
- カテゴリーの作成 / 編集 / 削除ができる
- カテゴリーの権限が変更できる
- カテゴリー一覧が取得できる

# 設計方針

Discord APIが提供する各エンドポイントについて適切な粒度でのラップを行います。基本的にはこの資料の「システム要件」セクションに記載の操作が行えるAPIエンドポイントを実装することが主たる目的となります。

詳細は[Discord APIリファレンス](https://discordpy-reborn.readthedocs.io/en/latest/api.html)の解読が終わり次第決定します。(解読よろしく @海苔扇子)
