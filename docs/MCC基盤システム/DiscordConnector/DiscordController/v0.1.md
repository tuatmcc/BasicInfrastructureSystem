# クラス設計

- 方針
    - PythonのProtocolを利用した静的ダックタイピングを導入し、抽象クラスを利用した依存関係の逆転を行う

```python

from typing import Protocol

# このクラスは共有モジュール内
# もしくは公開用API内で定義する
class IDiscordController(Protocol):
  def ...() -> ...:
      ...
      
# クラス定義本体
class DiscordController(IDiscordController):
    ...
```
